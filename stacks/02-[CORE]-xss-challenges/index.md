# XSS Challenges
- **Author**: Samuele Manclossi
- **Topic**: Cross-Site Scripting (XSS)
- **Type**: CORE

This is the second laboratory of the course of Web and Mobile Systems Security! In this laboratory, you will learn how to exploit Cross-Site Scripting (XSS) vulnerabilities in web applications. You will be introduced to different types of XSS attacks, including reflected, stored, and DOM-based XSS.
